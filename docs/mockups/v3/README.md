The V3 design (HAB-26–50), exported from Claude Design. Spec: `docs/specs/feature-spec-v3.md`; values: `docs/design/design-system-v3.md`.

Open a file through a local web server, not by double-clicking: the runtime fetches its own page, which `file://` blocks.

## Renders — read these first

`renders/` is generated by `npm run mockups:render` (`scripts/render-mockups.mjs`):

- `renders/INDEX.md` — every section, its slice count, and each frame ID (T1, P7, H4, DC1, …) mapped to the slice it sits in.
- `renders/<section>/text.txt` — all copy and rules as plain text. Start here for wording.
- `renders/<section>/slice_NN.png` — the page cut into 1800 px slices, for layout. **Gitignored** (~27 MB); run the script after a fresh clone or a design update.

Re-run the script whenever a `.dc.html` file changes, and commit the regenerated `INDEX.md` and `text.txt` files.

## Older versions

The V1 and V2 mockups were removed from the working tree in V3-6 (HAB-26–50) and live only at the git tag `mockups-v1-v2` (browse them with `git ls-tree -r mockups-v1-v2 docs/mockups`). They stay the reference for what was built before V3.
